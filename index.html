Core Infrastructure

Key Cloud & DevOps Concepts

AWS EC2 & Security Groups

Elastic Compute Cloud provides an on-demand IaaS Ubuntu virtual server in the cloud. A stateful Security Group acts as a virtual firewall, allowing inbound Port 80 (HTTP) for public web traffic and Port 22 (SSH) for automated deployments.

IaaS Virtual Server Port 80 HTTP Port 22 SSH

Docker Containerization

Packages the nginx:alpine web server together with the static HTML, CSS, and JavaScript files into a portable, immutable image. Eliminates "it works on my machine" drift so the app runs identically locally, in CI, and on AWS EC2.

nginx:alpine Immutable Image Consistent Runtime

GitHub Actions CI/CD

Delivers zero-touch automation on every git push to main. Verifies the container build, runs automated shell tests, and securely connects to EC2 over SSH using encrypted GitHub Secrets to redeploy with minimal downtime.

Zero-Touch Deploy Encrypted Secrets Automated Tests
